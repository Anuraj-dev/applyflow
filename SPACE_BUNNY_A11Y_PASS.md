# Space Bunny Accessibility Pass

- [ ] **Focus rings:** Every interactive control shows a clear, high-contrast focus indicator that is not clipped.
- [ ] **Dialogs:** Dialogs have accessible names, move focus inside on open, contain keyboard focus, close with Escape, and restore focus on close.
- [ ] **Discover checkboxes:** Each checkbox has a programmatic label, visible focus, Space-key support, and exposes its checked state.
- [ ] **Command palette:** The input and results use appropriate combobox/listbox semantics; arrow keys, Enter, and Escape work; the active option and result count are announced.
- [ ] **Verification:** Complete each flow using only a keyboard and confirm focus order, announcements, and contrast at 200% zoom.
